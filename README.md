# MouseSim — 鼠标键盘模拟器

Windows 桌面工具，面向**办公自动化**与**批量重复操作**：**录制**真实的鼠标键盘操作，之后一键回放；也可手动编排动作脚本，内置高频连点器与全局热键。

> 👉 使用说明见本文；**开发文档（架构 / 环境搭建 / 调试 / 测试 / 打包 / 二次开发指南）见 [DEVELOPMENT.md](DEVELOPMENT.md)**。

## 功能一览

| 模块 | 说明 |
|------|------|
| **录制回放** ⭐ | F9 开始/停止录制：真实操作（点击/双击/拖拽/滚轮/按键/组合键）自动转成动作脚本，含动作间真实停顿；录完可直接「保存并立即运行」或保存后在脚本页微调再跑 |
| **重复（脚本）** | 手动编排或编辑录制产物：8 类动作、循环次数（0=无限）、**按时长重复（X 分钟/小时后自动停）**、每步延迟、**重复速度标尺（×0.5 慢 ~ ×4 极速，7 档）** |
| **批量运行** | 勾选多个脚本按顺序批量执行，整批可循环 N 次或**按时长重复**；删除按钮同样作用于勾选脚本；F8 随时停止 |
| **连点器** | 可配置间隔（毫秒）、左/右/中键、单击/双击、跟随鼠标或固定坐标（支持坐标拾取）、有限次/无限次 |
| **全局热键** | 默认 **F6 开始 / F8 停止 / F9 录制**，可在设置中录制修改；任何程序前台都生效 |
| **脚本管理** | 新建/复制/重命名/删除，自动保存为 JSON（`%APPDATA%\MouseSim\scripts`） |

## 构建与运行

环境要求：.NET 8 SDK（本机已安装于 `C:\Develop\.Net`，命令行用 `C:\Develop\.Net\dotnet.exe`）。

```bash
# 开发运行
C:/Develop/.Net/dotnet.exe run --project src/MouseSim.App

# 运行测试（30 个用例）
C:/Develop/.Net/dotnet.exe test MouseSim.sln

# 发布为单文件 exe（输出在 publish 目录，双击即可运行）
C:/Develop/.Net/dotnet.exe publish src/MouseSim.App -c Release -r win-x64 --self-contained /p:PublishSingleFile=true -o publish

# 一键打包（在项目根目录双击 publish.bat，或命令行执行）
#   产出两个单文件 exe：
#   publish/MouseSim.exe      完整版 ~70MB，零依赖，任何 Win10 x64/Win11 可直接运行
#   publish/MouseSim-lite.exe 精简版 <1MB，要求目标机装有 .NET 8 桌面运行时
publish.bat
```

> 日常开发用 Debug 构建即可（依赖系统已装的 .NET 8 运行时）；分发给别人时用上面的自包含发布，目标机器无需安装任何东西。

## 快速上手

1. **录制回放**（最常用）：打开 MouseSim → 按 **F9** → 到目标程序里正常操作（点击、拖拽、滚动、按键）→ 再按 **F9** 停止 → 「保存并立即运行」，或「保存为脚本」后到脚本页修改细节（如删掉多余动作、改循环次数）再 F6 运行。
   - 对 MouseSim 自身窗口的点击不会被录进去；F6/F8/F9 热键也不会被录进脚本。
   - 动作之间的真实停顿会记录为等待：60 毫秒以下忽略（视作连续操作），超过 1 分钟截断。
   - 录中文：按键录制按“物理按键”回放，适合快捷键与英文输入；**输入法打出的中文建议在脚本页改成「输入文本」动作**（Unicode 直发，不依赖输入法状态）。
2. **连点器**：设置间隔 → 选择「固定坐标」→ 点「拾取坐标」，5 秒内把鼠标移到目标处 → F6 开始，F8 停止。
3. **手动脚本**：「＋ 添加」加入动作（坐标类动作默认取当前鼠标位置）→ 设循环次数/重复时长、拖「重复速度」标尺 → 运行。
   - 典型套路：`点击坐标` → `等待 500ms` → `输入文本` → `按键 Tab` → 循环 100 次，即可批量填表。
   - 速度标尺从「慢」到「快」共 7 档：所有等待/拖拽/按住时长按倍率缩放（×2 = 整体快一倍），随脚本保存；录制按正常节奏、回放拉快是最常用的组合。
4. **批量运行**：在「重复」页左侧勾选多个脚本（按列表顺序执行）→ 设整批循环次数/重复时长 → 点「▶ 批量运行」，F8 随时停止。
5. **设置**：点击热键框，按下想要的组合键（如 `Ctrl+Alt+S`），保存后即刻生效。

## 使用注意

- **权限**：模拟输入无法操作「以管理员身份运行」的程序（Windows UIPI 限制）。遇到目标程序没反应时，右键 MouseSim 快捷方式 → 以管理员身份运行。
- **安全软件**：录制使用系统低级钩子（WH_MOUSE_LL / WH_KEYBOARD_LL），个别杀软会提示“键盘监听”，属于本功能必需，请放行。
- **精度**：间隔与延迟基于系统调度，实际精度约 ±15ms；连点器间隔下限 10ms。
- **回放环境**：录制的坐标是绝对屏幕坐标，回放时目标窗口需在录制时相同的位置；分辨率/多屏布局变化后需重录或改坐标。
- **热键冲突**：热键被其他软件（含本软件）占用时会注册失败并在状态栏提示，换一个组合即可。
- **多显示器**：坐标为全屏物理像素，副屏在主屏左侧/上方时会出现负坐标，属正常现象。
- **数据位置**：脚本与设置在 `%APPDATA%\MouseSim\`，直接复制该目录即可备份或迁移。
- **故障排查**：异常日志在 `%APPDATA%\MouseSim\logs\error.log`。

## 设计要点

- **录制即脚本**：录制器产出的就是与手动编排完全相同的动作列表——录制 → 在脚本页编辑微调 → 回放，一条链路打通；宏录制不依赖界面其余部分，可独立演进。
- **录制状态机**（`MacroRecorder`）：按下/抬起之间小位移记单击，短时间同位置两次单击自动合并双击，大位移记拖拽（含真实时长），连续滚轮累计成一次滚动，修饰键组合识别，自动重复去重；动作间隔记为等待，与系统双击时间联动。
- **动作模型**：所有动作实现 `IAction`，经 System.Text.Json 多态序列化（`$kind` 判别）。
- **输入注入**：按键/滚轮走 `SendInput`；绝对移动用 `SetCursorPos`（像素精确、多显示器友好）；文本以 `KEYEVENTF_UNICODE` 发送，支持任意语言文字，不依赖键盘布局。
- **单任务模型**：同一时刻只允许一个任务运行（连点器或脚本），停止热键通过 `CancellationToken` 即时中断，绝不卡界面；录制中程序注入的事件自动被过滤，不会“自录自放”。
